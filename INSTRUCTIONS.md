Try Untangle (2 minutes)

Untangle is a Chrome extension I built that highlights hard-to-read sentences on any webpage. It's not published on the Chrome Web Store, so here's how to run it locally:

Download the code
Go to github.com/your-username/untangle → click the green Code button → Download ZIP → unzip it somewhere you'll remember (like your Desktop).
Open Chrome's extension page
Type chrome://extensions into your address bar and hit enter.
Turn on Developer Mode
Look for a toggle in the top-right corner labeled Developer mode — switch it on.
Load the extension
Click Load unpacked (top-left), then select the unzipped untangle folder.
Try it out
Visit any text-heavy page — a Wikipedia article works great — and you'll see complex sentences underlined in orange. Hover over one to see why it was flagged.

That's it — no sign-up, no install from the Web Store, nothing to configure. (There's also an optional AI-powered "Simplify" feature that needs a free API key to activate — not necessary to see the core project in action.)
