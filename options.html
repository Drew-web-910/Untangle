How to get your free key (2 minutes)

  1. Create a free account at huggingface.co/join
  2. Visit the Llama-3.2-3B-Instruct model page and click "Agree and access repository" — this step is required, approval is instant
  3. Go to huggingface.co/settings/tokens → Create new token → choose Read access → Create
  4. Copy the token (starts with hf_) and paste it above, then click Save

This key is stored only in your browser and is used only to call Hugging Face directly. It's never sent anywhere else. Detection and highlighting don't use this key at all — only the "Simplify this sentence" button does.
